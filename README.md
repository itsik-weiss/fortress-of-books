# מבצר המספרים

ערכה דיגיטלית להדפסה לכיתות ג׳–ד׳, עם **שני מסלולי עבודה בקבוצות**:

1. **חקירה ורמות חשיבה** — התלמידים מגלים בעצמם את חוקיות הזוגי והאי־זוגי ואת ערך הספרה לפי מקומה.
2. **חזרה, שינון ויישום** — פארק אתגרים חווייתי על מבנה עשרוני: קזינו ספרות, זירת בלשים, חנות שטרות, מסלול קפיצות וסדנת ממציאים.

## הרצה מקומית

דרושים Node.js 20+ ו-npm.

```bash
npm install
npm run dev
```

האתר נפתח בכתובת [http://127.0.0.1:43141](http://127.0.0.1:43141).

## מסלול החקירה

- 25 כרטיסיות מדורגות: זיהוי, חקירה, הסקת מסקנות
- 5 תחנות ל־4 תלמידים: מבצר הספרות, זוגות הגרביים, מגדל הכפל, בלשי המספרים, מעבדת המסקנות
- מערך שיעור של 45–50 דקות, שני סבבים
- דפים: [תחנות](/stations) · [כרטיסיות](/cards) · [מערך](/teacher) · [הדפסה](/print)

## מסלול החזרה · פארק האתגרים

- 25 משימות חווייתיות: תרגול, אתגר, יצירה
- 5 תחנות ל־5 תלמידים, 7 דקות לסבב + מעבר עם פעמון
- דרכון חותמות אישי וכרטיס חידה לקבוצה הבאה
- דפים: [פארק האתגרים](/review) · [כרטיסיות](/review/cards) · [מערך](/review/teacher) · [הדפסה](/review/print)
