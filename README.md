# מבצר המספרים

כרטיסיות חקירה במתמטיקה לכיתות ג׳–ד׳: **ערך הספרה** ו**חוקיות זוגי ואי-זוגי** בחיבור ובכפל.

הערכה בנויה לפי השיחה המקורית: 25 כרטיסיות מדורגות לעבודה ב-5 קבוצות של 4 תלמידים, עם רמזים מעוררי חשיבה, מערך שיעור ותצוגת הדפסה.

## מה יש כאן

- **תחנות צבעוניות** — מבצר הספרות, זוגות הגרביים, מגדל הכפל, בלשי המספרים, מעבדת המסקנות
- **חפיסה דיגיטלית** — כרטיסיות מתהפכות, רמז, ערבוב
- **הדפסה** — כרטיסיות לתלמידים בלי תשובות, מפתח למורה, דף תיעוד לכל קבוצה
- **מערך שיעור** — 45–50 דקות, שני סבבים, מליאת סיכום

## הרצה מקומית

דרושים Node.js 20+ ו-npm.

```bash
npm install
npm run dev
```

האתר נפתח בכתובת [http://127.0.0.1:43141](http://127.0.0.1:43141).

## קבצי PDF

ארבעה קבצים מוכנים להדפסה נמצאים בתיקייה `public/pdfs/` וגם בדף [הורדה והדפסה](/print):

- `כרטיסיות-לתלמידים.pdf`
- `מפתח-למורה.pdf`
- `דפי-תיעוד.pdf`
- `מערך-שיעור.pdf`

בנייה לייצור:

```bash
npm run build
npm start
```

## איך משתמשים בשיעור

1. פתחו את [מערך השיעור](/teacher) וחלקו את הכיתה ל-5 קבוצות.
2. כל קבוצה נכנסת לתחנה שלה או מקבלת כרטיסיות מודפסות ודף תיעוד.
3. קודם דוגמאות ומסקנה — ורק אז הופכים לתשובה.
4. במליאה מרכזים את טבלאות החיבור והכפל.

אין צורך בחשבון, מסד נתונים או מפתחות.
